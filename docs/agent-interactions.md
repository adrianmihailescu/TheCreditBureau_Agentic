# Agent interactions

The Orchestrator Agent tracks workflow state and handoffs. Customer, Broker, Bank, Credit Bureau, Risk, Compliance, and Frontend agents support their named participants or product area. The Orchestrator may request document extraction, notification drafting, or audit summaries from supporting roles.

All agents are advisory. Consent and authorization are prerequisites to bureau data; uncertain or missing information is surfaced rather than invented; the bank's authorized human credit officer makes lending decisions. Current agent files are prompt definitions, not running software.
